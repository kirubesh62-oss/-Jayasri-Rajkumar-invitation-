PUBLISH WITH GITHUB PAGES
1. Open your repository: https://github.com/kirubesh62-oss/jayasri-rajkumar-invitation
2. Tap Add file > Upload files.
3. Extract this ZIP on your phone first. Upload index.html and cover-couple.png (do not upload only the ZIP).
4. Commit changes.
5. Open Settings > Pages.
6. Under Build and deployment, choose Deploy from a branch.
7. Select Branch: main and Folder: /(root), then Save.
8. Wait for GitHub Pages to publish. The public URL will appear on the Pages settings screen.
